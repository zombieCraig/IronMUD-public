# Builder Documentation

Detailed OLC editor documentation. Start with [Builder Guide](../builder-guide.md) for an overview.

| File | Purpose |
|------|---------|
| `rooms.md` | Room editor (redit), doors, seasonal descriptions, liveable rooms |
| `items.md` | Item editor (oedit), types, containers, food, liquids |
| `mobiles.md` | Mobile editor (medit), shops, dialogue, daily routines, simulation, social/family, pregnancy |
| `socials.md` | CircleMUD-style social commands (`wave`, `bow`, …): format, tokens, tags, DG verb |
| `areas.md` | Area editor (aedit), permissions, spawn points, migrant immigration |
| `triggers.md` | All trigger types, Rhai scripting, examples |
| `dg-scripts.md` | DG Scripts (tbamud trigger language) — variables, commands, control flow, IronMUD specifics |
| `dialogue-trees.md` | Branching NPC dialogue: nodes, conditions, effects, MCP authoring |
| `quests.md` | Quest authoring (`quedit`): objectives, rewards, gates, dialogue hooks |
| `vampire-progression.md` | Sire-NPC + clan-embrace quest plumbing for thinblood progression |
| `mutant-progression.md` | Mutation Points, misfires, and the Rot — room contamination + mutant content plumbing |
| `worship.md` | God worship: deity mobs, pacts, tribute/anger ladder, temples, DG hooks |
| `factions.md` | Faction reputation: tags, opposed factions, standing bands, aggro, shop pricing, gating |
| `languages.md` | Language definitions, garbling, NPC `spoken_language` |
| `achievements.md` | Achievement editor (achedit), criteria and rewards |
| `custom-skills.md` | Builder-published "fake" skills (e.g. `dancing_queen`): registry + DG read/write + item affects |
| `classes.md` | Starting-kit editor (`admin loadout`, admin-only), per-class + per-race gold + item kit at character creation |
| `recipes.md` | Recipe editor (recedit), crafting system |
| `consignment.md` | Consignment brokers — the player-to-player market |
| `gardening.md` | Plant prototype editor (plantedit), gardening system |
| `attribution.md` | Who built what: `authored_by`, `origin`, and why an import counts for nothing |
| `world-rating.md` | The `world` command: tiers, caps, and the milestone wall |
| `bounties.md` | The help-wanted board: posting, claiming, and the half the auditor writes |
| `tracks.md` | Progress tracks and `build next`: area readiness and the Builder's Path |
| `score.md` | Builder points: how they are earned, why they cannot be farmed, and the boards |
| `audit.md` | `build audit` — content grading, the full check catalogue, and how to add a check |
